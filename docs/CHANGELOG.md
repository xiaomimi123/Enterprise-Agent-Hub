- 接入页改为「发一段话给员工的 agent，由 agent 自己执行安装命令」，员工不用打开命令行；补了新员工入职三步、管理员检查（端口、`HUB_HOST`）和常见问题，全部可一键复制。

- **根因**：没设价格的模型按 New API 默认倍率 37.5（每百万 $75）计费，费用严重虚高（CodeBuddy 单次请求约 $2），岗位包月度额度几小时被「花光」，之后网关返回 403。上线前必须给所有开放模型设价格。
