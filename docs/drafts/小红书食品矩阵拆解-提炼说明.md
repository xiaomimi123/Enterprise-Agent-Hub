## 2. 没有收录的，以及原因

报告的整体打法是**伪装成真实消费者的账号矩阵**，下面这些我没有写进知识库，因为中枢里的内容会被所有员工的 agent 当作业务标准去执行：

| 没收录 | 报告里的说法 | 原因 |
|---|---|---|
| 人设“分配”和虚构人设 | “店主女儿”“老爸工厂”“打工人”“复购者”人设；“素人号伪装真实消费者” | 虚构身份和经历，报告自己的风险清单也写了“虚假宣传风险” |
| 不标识的软文 | “伪装不是广告”“伪装自来水”；“求推荐体规避广告感” | 报告自己写“软文广告未标识”（广告法口径） |
| 自问自答的评论区 | “评论区天然可自答植入，比种草更隐蔽” | 自己的账号互相捧场，制造真实用户假象 |
| 防识别矩阵 | “同源文案做多样性扰动，防平台识别矩阵”；“搜索结果页占位工程”；“账号死了换号重来” | 目的就是规避平台检测，和项目既定规则（不做反检测伪装）一致 |
| 30 天养号 SOP（原样） | 纯情绪内容养号 → 搜索词占位 → 种草上量 → 企业号收口 | 原版是上面几项的执行手册，**拆开收录**：节奏骨架（先不带产品的品牌 / 日常内容 → 对应真实搜索词的有用笔记 → 产品种草 → 活动收口）已收进知识库「十一、新账号起步」；伪装人设、互相捧场、自问自答、买互动这些没收（2026-10-28 用户指出新号前期发非产品内容是正常节奏，据此补充） |
| 误导式封面 | “效果前置：封面放门店级成品，正文才说是 3 块钱冻干冲的——先骗点击” | 封面与实物不符 |
| 涂鸦求助体封面 | “把广告伪装成生活求助帖” | 同上，伪装广告 |
| 编造“像真的”的价格 | “8.4r（非整数才像真实标价，8 块就假了）” | 改成“写真实价格和规格” |

## 3. 看了封面图后的补充

抽看了 3 张（咖啡模版 1、腐乳封面、粉剂封面）：

- 咖啡“模板”拍的是**瑞幸的杯子**（他牌杯子 + logo 当自家冻干咖啡的封面）
- 腐乳封面是**他牌产品的超市货架**
- 粉剂封面是 **AI 生成的场景**，罐子标签是乱码；封面文字有“治愈”，素材文件名里有“消炎益脑”——食品类不能宣称治疗 / 功效，也与知识库《广告法极限词表》里的医疗用语冲突

所以**图片本身没有导入**（带他牌标识、功效宣称、虚假标签），只提炼了版式原则；知识库文档的合规一节和质检清单里加了两条对应的规则（不用他牌杯子 / 包装 / 货架；食品不宣称治疗或功效）。其余封面图、4 个视频我没有逐一看。

## 5. 怎么上线

文档放在 `vault/` 里只是方便管理；**线上知识库的文档存在数据库里**（见 [../knowledge.md](../knowledge.md)），需要管理员在控制台「知识库」页上传：

1. 控制台 → 知识库 → 选「历史爆款笔记」→ 新建文档，标题「小红书食品类目运营方法论」，把 `vault/历史爆款笔记/小红书食品类目运营方法论.md` 的内容粘贴进去（或导入文件）。
2. 在「知识库」页设好负责人和复核周期（建议 3 个月，平台规则会变）。
3. 员工岗位包要包含「历史爆款笔记」才能检索到。
