# 知识库：品牌与产品（冲剂 / 饮料版）草稿

> 写于 2026-10-28。现有知识库里的品牌调性、产品资料、爆款笔记是护肤品演示数据（「星河」保湿精华 / 防晒乳），和实际产品（冲剂、饮料等）对不上。下面是替换用的**结构草稿**：能确定的写了，**品牌名、产品、价格、人群这些事实用【待填】标出，需要运营主管或你补**。内容怎么定、人设是什么，由运营主管决定，这里只给选项和写法。
>
> 上线方式：知识库文档存在数据库里，需要有权限的人在控制台「知识库」页改。建议顺序：先在对应知识库里新建下面的文档（填好事实）→ 再把旧的护肤演示文档删除（删除保留历史版本，可回滚）。

---

## 文档 1：品牌人设定义（知识库「品牌调性与人设」，替换原文档）

```markdown
# 品牌人设定义

## 品牌
【待填：品牌名 / 小红书账号名】主营【待填：冲剂、饮料等产品线】。

## 人设（运营主管二选一或自定）
- 选项 A「会吃会喝的朋友」：分享自己真实在喝、在用的东西，像朋友推荐，专业但不说教
- 选项 B「研发 / 工厂视角」：讲配方、原料、工艺，用真实的人和事建立信任
- 选项 C【待填：主管自定】

## 语气
- 多用第一人称「我」，少用「我们公司」
- 先讲场景和感受（早起、加班、睡前、运动后），再讲配料和做法
- 口语化、短句；一篇笔记一个情绪钩子
- 不贬低竞品，不制造焦虑

## 建议避免的表达
- 极限用语：「全网最低」「第一品牌」「最好喝」等（见《广告法极限词表》）
- 食品类的疾病治疗或保健功效暗示：「治疗」「治愈」「消炎」「益脑」「调理」「排毒」等；只讲口感、冲泡方法、场景和真实的使用感受
- 与实物不符的描述（口味、规格、配料）
```

```markdown
# 【待填：产品名】 产品卖点

- 品类：冲剂 / 饮料 / 【待填】
- 口味 / 版本：【待填】
- 配料与关键成分：【待填：以包装配料表为准】
- 规格与保质期：【待填：克数 / 毫升、袋数、保质期、储存方式】

- 适合场景 / 人群：【待填：早餐、办公室、运动后、睡前……】
- 规格与价格：【待填：日常价；活动价以运营通知为准】
- 可以说：【待填：真实、可验证的卖点，如「0 蔗糖」「速溶 10 秒」要有依据】
- 不能说 / 建议避免：疾病治疗和保健功效（如「消炎」「益脑」「治愈」「调理」）、绝对化用语（「最好喝」「第一」）、与检测报告不符的数据
- 资质与依据：【待填：检验报告、生产许可、配料来源，用来支撑上面的说法】
```
