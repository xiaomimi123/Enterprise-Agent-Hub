# 1 文档说明

本文档是「三年级六班集团 · 企业智能体中枢」（下称「中枢」）的开发与架构文档，面向后续参与开发、部署和运维的工程师，也供技术负责人评审设计决策。它描述系统**为什么这样设计**、**关键机制如何工作**以及**代码在哪里**，不重复源码中已经写清楚的细节。

这是 2.0 版。相比 1.0（2026-10-17），产品从「权限 + 知识 + 算力」的最小链路，扩展为一个可以日常使用的管理平台：多角色控制台（管理员 / 老板 / 部门主管）、技能库与知识库的在线编辑与版本治理、agent 提交改进建议、工作成果与日报、应用分发与依赖预检。这些新增内容集中在第 6、8、9、13、14 章，其余章节按当前代码做了同步更新。

## 1.2 阅读约定

- 代码片段均从仓库**构建时原样摘取**（文档由 `tools/docs` 从源码生成），路径写在片段上方；为节省篇幅，个别片段会截断较长的函数。
- 「岗位包」指一组权限配置：技能、知识库、工具、模型、额度和安全策略。员工通过部门默认或单独指派获得岗位包。
- 「官方 agent」指用中枢 `hub-agent` 应用登录的员工端；「外部智能体」指 ChatGPT 等第三方，经 `hub-external` 应用只读接入。
- 「控制台角色」与「岗位包」是两件事：岗位包管员工的 agent 能做什么，控制台角色（管理员、老板、部门主管）管人在控制台里能看和改什么（4.5 节）。
- 金额以人民币计；New API 的额度单位为 500000 = 1 美元，按 `HUB_USD_CNY`（默认 7.2）折算。
- 文中「已验证」指在本机真实环境跑通过，「未验证」会明确写出。
