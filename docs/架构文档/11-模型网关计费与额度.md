# 11 模型网关、计费与额度

模型调用走 New API（开源的 OpenAI 兼容网关）：每位员工一个专属 key，网关按 key 记日志，控制台据此按人、按部门、按模型统计。中枢要做的是把**岗位包的限制落到员工的 key 上**，并把**模型价格**设对，否则额度会失真。

## 11.1 两种模型方式

| 方式 | 员工得到什么 | token 由谁计量 | 适用 |
|---|---|---|---|
| 中枢模型 | New API 员工专属 key（`hub-<组织>-<用户>`） | New API 按 key 记日志，控制台按人统计 | Hermes、CodeBuddy CLI 等可以使用中枢下发模型的 agent |
| 自带模型 | 不发 key | agent 厂商自己的积分 | WorkBuddy、Cursor、Claude 桌面版 |

CodeBuddy CLI 属于「中枢模型」：接入器会把岗位包允许的中枢模型写进 `~/.codebuddy/models.json`（条目名带「公司中枢 · 」前缀，地址是网关的 `/v1/chat/completions`），员工本人的 key 作为 `apiKey`，所以用量记到本人名下。

## 11.2 岗位包落到员工 key：plan_key 算法

员工每次领取配置时，中枢重新计算并更新其 key 的模型限制与剩余额度。规则写成纯函数，便于测试：

- **可用模型** = 岗位包勾选的模型 ∩ 网关里启用渠道的真实模型；交集为空（例如岗位包仍是旧的演示模型名）时**只放行默认模型**，既不会让人突然不可用，也不会放开全部模型。
- **下发给 agent 的模型**：默认模型在可用范围内就用它，否则用第一个可用模型。
- **剩余额度** = 月额度（人民币）换算的额度 − 本月已用额度，下限为 0；月额度 0 表示不限。本月已用按调用日志统计（New API 的累计用量不分月），每次同步重算，**跨月自动恢复**。

剩余额度公式：remain = max(0, round(monthly_cny / usd_cny × 500000) − used_this_month)。

## 11.3 模型价格：没设价格会让额度几小时耗尽

员工的用量费用、月度额度、岗位包的成本统计，都按网关里的模型价格计算。**没有设置价格的模型，New API 按默认倍率 37.5（每百万 token $75）计费**，费用严重虚高：例如 CodeBuddy 每次请求带约 2.5 万 token 上下文，单次就扣约 $2，岗位包的月度额度几小时就被「花光」，之后请求被网关以 403 拒绝。这是真实踩过的坑。

控制台「模型」页的「模型价格」让管理员按**美元 / 百万 token** 填每个开放模型的输入价和输出价（输出价留空则与输入价相同），保存后立即生效：

- 实现：写 New API 的 `ModelRatio`（输入倍率 = 输入价 ÷ 2，倍率 1 = 每百万 $2）和 `CompletionRatio`（输出倍率 = 输出价 ÷ 输入价）；只改所选模型，其他模型的价格原样保留；「恢复默认」清除该模型的自定义价格。
- 页面会提示「N 个模型还没设置价格」；每次设置 / 清除写审计（`model.pricing.set` / `model.pricing.clear`）。
- 已对真实 New API 验证：同一个 35 输入 + 5 输出 token 的请求，没设价格时扣 1500 额度，设成 $0.14 / $0.28 后只扣 3。

## 11.4 中枢资源计量

无论员工用哪种 agent，中枢都计量自己承担的资源，数据完全来自审计日志和任务队列，不依赖任何第三方：

| 指标 | 口径 |
|---|---|
| 工具调用 | 审计中结果为「通过」的检索、技能、生成派发；登录、被拒绝的请求不计。调度服务写的完成记录类型为「生成」，避免一次生成被算两次 |
| GPU 用时 | 任务开始到结束的实际时长（失败的任务也计，因为 GPU 确实被占用）；第三方出图 API 任务不计 |
| 出图 / 视频 | 已完成任务的输出文件，按扩展名区分图片与视频 |

## 11.5 额度与限流

| 机制 | 作用对象 | 超限行为 |
|---|---|---|
| 并发限制 | 每人未完成（排队 + 运行）生成任务 ≤ `HUB_GPU_MAX_PENDING_PER_USER`（默认 3） | MCP 提示稍后再试；HTTP 429；记拦截审计 |
| GPU 月额度 | 岗位包 `gpu_quota_minutes`，按本月 GPU 秒数累计（运行中的算到当前） | MCP 提示；HTTP 403；记拦截审计 |
| 模型月额度 | 岗位包「每人月模型额度」，写入 New API key 的剩余额度 | 网关拒绝调用 |
| 改进建议限额 | 每人每天最多 10 条（8 章） | 工具返回说明，不入库 |
