# 17 接口参考

接口分为三类：员工端接入（接入器和安装脚本使用）、生成接口（员工令牌鉴权的 HTTP 入口）、控制台 API（会话 cookie，按角色限制）。下表以 FastAPI 生成的路由为准（共 92 个方法 + 路径组合）。控制台接口的「角色」列：**管**=仅管理员，**老**=老板可用，**主**=部门主管可用（只含自己部门）；老板和主管能用的写接口还会由处理函数再判断具体对象（4.5 节）。

## 17.1 员工端接入（/api/agent，console-web 8088 转发）

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/agent/config` | 公开 | Casdoor 地址、client id、回调地址、MCP 地址 |
| POST | `/api/agent/token` | 开发环境 | 账号密码登录（需 `HUB_AGENT_PASSWORD_LOGIN=true`） |
| POST | `/api/agent/enroll` | 员工令牌 | 领取模型 key、MCP 地址、岗位包技能全文（已生效版本）；按岗位包更新 key；写登录审计 |
| POST | `/api/agent/heartbeat` | 员工令牌 | 在线心跳：client、version、os |
| POST | `/api/agent/open-app` | 员工令牌 | 核对岗位包，返回应用启动凭证（给不走 MCP 桥的客户端） |
| POST | `/api/agent/app-event` | 员工令牌 | 接入器回报应用启动结果（含缺失的能力），写审计 |
| POST | `/api/agent/work-report` | 员工令牌 | 接入器转发应用的成果（一次最多 50 条，按 key 幂等） |
| GET | `/api/agent/hub_agent.py` | 公开 | 下载接入器（不含密钥） |
| GET | `/api/agent/install.{ps1\|sh}` | 公开 | 一键接入脚本，已填中枢地址 |

## 17.2 生成接口（/api/v1，员工令牌）

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| POST | `/api/v1/images` | JSON：prompt、aspect、count | 202：task_id、ahead、trace_id |
| POST | `/api/v1/videos` | JSON：prompt、aspect、seconds | 202 |
| POST | `/api/v1/videos/from-image` | multipart：image、prompt、seconds | 202；非图片 400 |
| GET | `/api/v1/tasks/{id}` | — | 状态、节点、images / videos 签名链接、耗时 |

错误码：401 未登录或令牌无效；403 无权或 GPU 月额度用完；400 参数非法；429 未完成任务过多。可用请求头 `X-Hub-Trace-Id` 指定追踪 ID。

## 17.3 控制台登录与公开资源

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/auth/login` | 返回 Casdoor 授权地址（state 存 httpOnly cookie） |
| POST | `/api/auth/callback` | 用授权码换令牌，写会话 cookie `hub_session` |
| GET | `/api/auth/me` | 当前用户、角色（admin / boss / manager）、负责的部门 |
| POST | `/api/auth/logout` | 清除会话并作废 Casdoor 令牌 |
| GET | `/api/health` | 健康检查（公开） |
| GET | `/api/files/{task}/{name}` | 签名下载生成结果（无需登录，`exp` + `sig` 校验） |
| GET | `/api/apps/{id}/{filename}` | 签名下载应用包（10 分钟有效） |

## 17.4 控制台 API（/api，会话 cookie）

| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/overview` | 管 老 | 总览：在线、任务、花费、拦截、GPU |
| GET | `/api/departments`、`/api/members` | 管 老 主 | 部门与成员（主管只含自己部门） |
| POST / PATCH / DELETE | `/api/members`、`/api/members/{id}` | 管 | 新建 / 编辑 / 删除成员 |
| POST | `/api/members/{id}/password`、`/enabled`、`/api/members/import` | 管 | 重置密码 / 停用启用 / CSV 批量导入 |
| PUT | `/api/members/{id}/role-pack` | 管 | 为成员指派岗位包 |
| GET / POST / PUT / PATCH / DELETE | `/api/org`、`/api/org/departments[/{id}]`、`/managers`、`/default-pack`、`/bosses` | 管 | 部门、主管、老板、默认岗位包 |
| GET / PATCH | `/api/role-packs[/{id}]` | 管（读：老 主） | 岗位包（读取给成员页显示岗位包名；修改仅管理员） |
| GET | `/api/catalog` | 管 老 | 岗位包编辑时可选的技能、知识库、工具、模型、应用目录 |
| GET / POST / PUT | `/api/skills`、`/api/skills/{id}`、`/history` | 管 老 主 | 技能列表、详情、版本历史、保存、新建 |
| POST | `/api/skills/{id}/rollback` | 管 老 主 | 回滚（权限按 `plan_for`） |
| GET / POST | `/api/skill-reviews`、`/api/skill-reviews/{id}/{version}` | 管 老（主：看自己的） | 待审核 / 通过或驳回 |
| GET / POST / PATCH | `/api/knowledge-bases[/{id}]`、`/reviewed` | 管 老 主（新建：管 老） | 知识库列表、新建、属性、标记已复核 |
| GET / POST / PUT / DELETE | `/api/knowledge-bases/{id}/documents[/{name}]`、`/rollback`、`/deleted`、`/sync` | 管 老 主 | 文档的查看、新建、保存、删除、回滚、重试同步 |
| GET / POST | `/api/kb-reviews`、`/api/kb-reviews/{kb}/{name}/{version}` | 管 老（主：看自己的） | 文档待审核 / 通过或驳回 |
| GET / POST | `/api/proposals[/{id}]`、`/accept`、`/reject` | 管 老 主 | 改进建议：列表、详情、采纳、驳回 |
| GET | `/api/work/report` | 管 老 主 | 工作看板（主管只含自己部门） |
| GET | `/api/audit/traces[/{id}]` | 管 老 | 审计链路 |
| GET | `/api/gpu/tasks`、`/api/usage`、`/api/apps` | 管 老 | 生成任务、用量与成本、已发布应用 |
| GET | `/api/connect` | 管 | 员工接入方式 |
| GET / PUT / DELETE / POST | `/api/models/upstreams`、`/pricing[/{model}]`、`/image/*`、`/h3`、`/video/route` | 管 | 对话模型上游、模型价格、出图 API 与通道、H3 网关、视频通道 |

老板和主管没有列出的接口一律 403（默认拒绝）；管理员可以访问全部。接口文档在后端的 `/docs`（开发环境）。
