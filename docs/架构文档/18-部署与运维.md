# 18 部署与运维

当前部署是**本机 Docker Desktop 开发环境**（一台 Windows 电脑同时跑中枢、RAGFlow 和 ComfyUI），已用于全流程验证。云服务器部署（香港 + 隧道连本地 GPU）暂缓，等本地功能测完再做。部署细节见 `hub/README.md`。

## 18.1 首次部署

1. 生成环境变量：`make env`（随机密码），修改 `HUB_HOST`、`CASDOOR_ORIGIN`（服务器局域网 IP）、`HUB_ORG`、`HUB_GPU_NODES`。
2. 启动中枢：`make up`（`docker compose up -d --build`；PostgreSQL 首次初始化后若有服务未就绪，再执行一次）。
3. 初始化 Casdoor 与 New API：`make bootstrap`（开发 / 演示用 `make bootstrap-demo`，会额外创建测试部门、成员、模拟模型和模拟 GPU 节点）；凭证写回 `.env`。
4. RAGFlow：`make ragflow-up` → `make ragflow-bootstrap`（写入 API Key）→ `docker compose up -d`（让 console-api、hub-mcp 读到新配置）→ `make kb-sync`。
5. 在控制台「模型」页添加真实对话模型上游并开放模型，**为每个开放的模型设置价格**（11.3 节）；设 `HUB_DEFAULT_MODEL`。
6. 在控制台「部门与角色」页设置部门、主管、老板；在「成员与组织」创建或批量导入成员；在「岗位包」里给岗位勾选技能、知识库、工具、模型和可打开的应用。
7. 中枢机防火墙放行 8088 / 8200 / 8000 / 3000（仅专用网络）；ComfyUI 监听地址改为 127.0.0.1。

## 18.2 发布应用的新版本

应用（如小红书运营工作台）在独立仓库开发。发布新版本：改应用的版本号并更新其更新日志 → 提交 → 打包（`node tools/package.mjs`，包由 `git archive` 生成，未提交的不进包）→ 把 zip 复制到中枢 `apps/<应用>/<版本>.zip` 并把同目录 `app.json` 的 `version` 改成同一个版本。**不需要重启中枢**；员工下次打开时自动拿到新版（正在运行的实例不会被重启，只提示升级）。**每次重新上传都必须升版本号。**

## 18.3 Windows 平台注意事项

| 问题                    | 现象                                               | 处理                                                |                         |
| --------------------- | ------------------------------------------------ | ------------------------------------------------- | ----------------------- |
| CRLF 换行               | PostgreSQL 初始化脚本报 `/bin/bash^M: bad interpreter` | `.gitattributes` 固定 `*.sh` 为 LF；转换后 `down -v` 重建  |                         |
| Hyper-V 保留端口          | ES 端口 1200 绑定失败                                  | setup.sh 改为 19200                                 |                         |
| TEI 内存峰值              | 预热阶段被 OOM（退出码 137）                               | override 把 `--max-batch-tokens` 降到 2048，稳定在约 3GB  |                         |
| source .env           | 含空格和 \`                                          | \` 的值被 shell 当命令执行                                | setup.sh 逐行解析 KEY=VALUE |
| GBK 控制台               | 打印符号或读中文文件时编码错误                                  | 文件读写显式 UTF-8；脚本加 `PYTHONUTF8=1`                   |                         |
| 防火墙阻止规则               | 容器经 host.docker.internal 访问宿主机也算入站               | 不要用阻止规则拦 8188，改为 ComfyUI 只监听 127.0.0.1（已实测容器仍可访问） |                         |
| Docker 拉镜像偶发失败        | 构建时 `ghcr.io` 握手失败                               | 重试即可（网络偶发）                                        |                         |
| `navigator.clipboard` | http 下不可用，复制按钮失效                                 | 前端用 `copyText`（`lib.ts`）兜底                        |                         |

## 18.4 日常运维

- **更新代码后重建**：`cd hub && docker compose build console-api console-web && docker compose up -d --force-recreate console-api hub-mcp hub-worker console-web`（改了安装脚本或后端 / 前端之后）。
- **技能与知识库在控制台里改**，改完即生效，**不需要**也**不应该**再改磁盘上的 `skills/`、`vault/`；知识库检索的全量对齐用 `make kb-sync`。
- **查看调度日志**：`docker compose logs -f hub-worker`；容错改派与失败都会写 warning 和审计。
- **备份**：PostgreSQL（`pg_dump hub`、`casdoor`、`newapi`，技能和知识库的全部版本都在里面）、`hub/.env`、`hub/data/outputs/`、RAGFlow 数据卷。
- **成员离职**：在控制台「成员与组织」停用或删除，立即禁止登录，已签发的令牌最多 30 秒内失效，并回收其模型 key。
- **没设价格的模型会让额度几小时耗尽**，新增模型后先去「模型」页设价格。
- **不要对真实 `%APPDATA%` 跑接入器 `setup`**：它会往 Claude 桌面版配置里加 `enterprise-hub`；测试用隔离的 `USERPROFILE` / `APPDATA` 或 `HUB_INSTALL_DRYRUN=1`。
