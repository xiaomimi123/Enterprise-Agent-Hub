# 19 安全设计汇总

| 威胁                | 缓解措施                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| 越权访问知识库           | 岗位包前置过滤 + 结果层二次丢弃；拦截写审计；知识库的部门、密级、是否开放外部由管理员 / 老板控制                                                |
| 提示词注入             | 权限在工具实现中判定，与模型输出无关；客户端将工具结果标为不可信数据；agent 提交的建议只给人看差异，从不自动执行                                        |
| 主管越权看别的部门 / 改系统配置 | 控制台接口**默认拒绝**：老板和主管只能用白名单，主管的数据按部门过滤；新增接口默认只有管理员能用                                                 |
| agent 直接改技能或知识库   | agent 只能提建议；采纳由人决定；每次修改都是新版本，可回滚；全公司内容的修改需老板 / 管理员审核                                               |
| 授权码截获             | 员工端 PKCE；中枢不代换授权码；回调校验 state                                                                       |
| 令牌伪造 / 冒用入口       | JWKS 验签；受众白名单；入口由签发应用决定而非请求头；控制台令牌不被 MCP 接受                                                        |
| 离职员工继续使用          | 停用即回收模型 key；已签发令牌按账号状态在 30 秒内拒绝                                                                    |
| SSRF              | 图生视频只接受中枢签发链接；不抓取任意 URL                                                                            |
| 路径穿越              | 签名下载校验解析后路径位于输出目录内；应用包解压拒绝绝对路径、`..`、符号链接                                                           |
| 恶意应用包             | SHA-256 校验（中枢按文件内容计算）；解压限制总大小和文件数；不允许 `requires` 出现未知的能力（写错的应用不出现在列表里）                             |
| 签名伪造 / 计时攻击       | HMAC-SHA256 + 过期时间；`hmac.compare_digest` 常数时间比较                                                    |
| 资源滥用              | 每人并发上限（429）、GPU 月额度（403）、模型月额度（网关拒绝）、改进建议每天 10 条                                                   |
| 敏感数据进入审计或成果       | 配置审计只记谁改了什么，不记内容和密钥；成果只存标题 / 状态 / 公开链接；应用上报前清洗，丢弃本机路径                                              |
| 密钥泄露              | `.env` 不入库；接入器不含任何应用密钥；出图 API 与网关密钥用 `HUB_FILE_SECRET` 派生密钥加密，只显示后四位；模型 key 只在领取配置时下发到员工本机（权限 600） |
| 修改别人的配置文件出错       | 接入器只增改一项、改前备份、幂等、格式有误不覆盖                                                                           |
| 未鉴权的 ComfyUI      | 只监听本机；中枢容器经 host.docker.internal 访问                                                                |
| 恶意上传              | 大小上限 10MB；Pillow 校验格式；文件名由中枢生成                                                                     |
| 应用自动发布 / 越权操作账号   | 应用里的 agent 默认只读：禁用写类浏览器工具，测试档需用户明确授权并屏蔽创作者中心；发布由员工本人完成                                             |

> **待加强**：安装脚本与 API 目前经局域网 HTTP 传输，只适合公司内网；对外提供服务前需上 HTTPS（反向代理 + 证书），并开启 `HUB_COOKIE_SECURE`。另外，应用自带的模型密钥（生图、视频）还没统一到中枢，额度和审计暂时不在中枢侧。
