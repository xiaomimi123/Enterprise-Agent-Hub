# 附录 A 配置项

## A.1 中枢后端（环境变量）

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `HUB_CONSOLE_MODE` | demo | demo（演示数据，无需登录）/ casdoor（真实数据） |
| `HUB_DATABASE_URL` | — | 中枢数据库连接串（casdoor 模式必填；技能、知识库、角色、建议、成果都在里面） |
| `CASDOOR_ENDPOINT` / `CASDOOR_PUBLIC_URL` | — | 服务端访问地址 / 浏览器访问地址 |
| `CASDOOR_ORG` / `CASDOOR_APP` | — | 企业组织名 / 控制台应用名 |
| `CASDOOR_CLIENT_ID` / `CASDOOR_CLIENT_SECRET` | — | 控制台应用的 OAuth 凭证（同时用于读取和管理成员、部门） |
| `HUB_AGENT_CLIENT_IDS` / `HUB_EXTERNAL_CLIENT_IDS` | — | 官方 agent / 外部智能体应用的 client id（逗号分隔） |
| `HUB_AGENT_PASSWORD_LOGIN` | false | 开发环境账号密码登录开关 |
| `NEWAPI_ENDPOINT` / `NEWAPI_PUBLIC_URL` | — | New API 服务端 / 员工端地址 |
| `NEWAPI_ACCESS_TOKEN` / `NEWAPI_ADMIN_ID` | — | 管理接口凭证（bootstrap 写入；用于渠道、key、模型价格） |
| `HUB_DEFAULT_MODEL` | — | 员工默认模型 |
| `HUB_USD_CNY` | 7.2 | 额度折算汇率 |
| `HUB_GPU_NODES` | — | 「id｜名称｜ComfyUI 地址｜显卡说明」，逗号分隔 |
| `HUB_GPU_MAX_PENDING_PER_USER` | 3 | 每人未完成生成任务上限 |
| `HUB_IMAGE_API_CONCURRENCY` / `HUB_H3_CONCURRENCY` | 4 / 2 | 第三方出图 API / H3 网关同时处理的任务数 |
| `HUB_FILE_SECRET` | 随机 | 下载链接签名密钥，同时派生用于加密存放第三方密钥的密钥（更换后已保存的密钥作废） |
| `RAGFLOW_ENDPOINT` / `RAGFLOW_API_KEY` | — | 两项都有才启用 RAGFlow |
| `RAGFLOW_EMBEDDING_MODEL` | Qwen/Qwen3-Embedding-0.6B | TEI 嵌入模型 |
| `HUB_SKILLS_DIR` / `HUB_VAULT_DIR` | 仓库内目录 | 技能和知识库的**初始数据**目录：首次启动导入数据库，之后以数据库为准 |
| `HUB_WORKFLOWS_DIR` / `HUB_AGENT_DIR` / `HUB_APPS_DIR` / `HUB_OUTPUTS_DIR` | 仓库内目录 | ComfyUI 工作流、接入器、应用发布目录、生成结果目录（容器内为 /data/*） |
| `HUB_MCP_PUBLIC_URL` | `http://localhost:8200/mcp` | MCP Server 对外地址 |
| `HUB_COOKIE_SECURE` | false | 启用 HTTPS 后设为 true |

## A.2 接入器与应用（环境变量）

| 环境变量 | 说明 |
|---|---|
| `HUB_AGENT_HOME` | 接入器的本机目录（默认 `~/.hub-agent`） |
| `HUB_CODEBUDDY_HOME` / `HUB_WORKBUDDY_SKILLS` | CodeBuddy 配置目录 / WorkBuddy 技能目录（默认在用户目录下，测试时可重定向） |
| `HUB_INSTALL_DRYRUN` | 一键脚本：只演练不落盘（测试时必用，避免改真实配置） |
| `HUB_INSTALL_TOOLS` | 一键脚本对缺失的 Node.js / CodeBuddy CLI：`yes` 不询问直接安装，`no` 一律不装也不询问，不设置则交互询问（没有交互终端时跳过） |
| `HUB_BRIDGE_NESTED` | 嵌套桥（应用里的 agent 用），不同步技能、不报心跳 |
| `HUB_MCP_SERVERS_FILE` / `HUB_TRACE_ID` / `HUB_CAPABILITIES_FILE` / `HUB_WORK_OUTBOX` | 接入器启动应用时设置的对接契约（14.2 节） |

# 附录 B 仓库结构

| 路径 | 内容 |
|---|---|
| `console/backend/app/` | 后端：`main`（控制台 API）、`mcp_server`、`agent_api`、`public_api`；权限与角色 `policy`、`auth`、`roles`、`depts_api`；治理 `skillstore` / `skills_api`、`kbstore` / `kb_api` / `kbmeta`、`proposals` / `proposals_api`、`work`；内容与检索 `content`、`ragflow`、`kb_sync`；算力 `generation`、`gpu`、`comfyui`、`imageapi`、`h3gateway`；模型 `newapi`、`models_api`、`model_upstreams`、`metering`；其他 `db`、`presence`、`members_admin`、`app_access`、`apps`、`settings_store`、`secretbox`、`providers/` |
| `console/backend/tests/` | 350 个自动化测试 |
| `console/backend/scripts/` | casdoor / newapi / ragflow 初始化、`ragflow_sync`、`mcp_smoke`、`gpu_smoke`、`e2e_proposals`（端到端） |
| `console/frontend/src/` | `theme.tsx`、`api.ts`、`auth.tsx`、`layout/`（按角色的菜单）、`pages/`（含 `Org`、`Skills` + `SkillEditor`、`Knowledge` + `KbDocs` + `KbSettings`、`Proposals`、`Work` 等）、`ui/`、`components/`（`EChart`、`DiffView`） |
| `agent/` | `hub_agent.py`（接入器）、`install.ps1`、`install.sh` |
| `apps/` | 应用发布目录（zip 与 `app.json` 不入库，只在部署机上） |
| `gpu-node/workflows/` | ComfyUI 工作流模板 |
| `hub/` | `docker-compose.yml`、`.env.example`、`Makefile`、`ragflow/`、`postgres/`、`casdoor-static/` |
| `skills/`、`vault/` | 技能与知识库的**初始数据**（首次启动导入数据库，之后在控制台编辑） |
| `tools/docs/` | 本文档的生成工具（Markdown → Word + PDF） |
| `docs/` | `CHANGELOG.md`（每次重要更新）、专题文档（`console-roles`、`skills`、`knowledge`、`proposals`、`work-report`、`app-integration-guide`、`mcp-server`、`agent`、`gpu`、`billing` 等）、本文档的源（`架构文档/`）与成品 |
