# 1 一页读懂

**一句话**：智能体中枢是公司内部的「AI 管理中心」——统一管账号、权限、公司知识、做事标准、模型费用和算力，并记录每一次调用；员工继续用自己顺手的 AI 助手干活，但所有助手都按公司的标准、在公司划定的边界内工作。**小红书运营工作台**是接在中枢上的第一个岗位应用，帮运营完成对标分析、选题、文案、封面和数据复盘，并且**只做只读分析，不会自动发布**。

## 1.1 三个核心价值

| 价值 | 说明 |
|---|---|
| 标准统一 | 公司的做事流程（技能）和资料（知识库）由主管在中枢里维护，所有员工的 AI 助手读的是同一份，不再「各用各的、各写各的」 |
| 风险可控 | 谁能用什么、能看哪些资料，由中枢在服务端判定；越权会被拒绝并留记录；模型花费按人计量、有月度额度 |
| 过程可见 | 员工做成了什么、哪里报错、谁在线、花了多少钱，老板在控制台一屏能看到；AI 发现标准有问题只能提建议，由人审核后才生效 |

## 1.2 现在做到了什么

| 项目 | 现状 |

| 员工电脑安装 | 一条命令完成安装，装之前先自检，并在全新的 Windows 虚拟机上完整走通；已有员工电脑在试用并反馈问题 |
| 阶段 | **同事试点阶段**。运行在本机 Docker 环境，上云（香港云服务器）的计划暂缓，先在本地把功能测完 |

## 1.3 为什么值得继续投入

- **不绑定某一个 AI 工具**：员工用 WorkBuddy、CodeBuddy 或其他 AI 助手都可以，中枢只管「经过中枢的资源」，将来换工具不用推倒重来。
- **第一个岗位就是真实业务**：小红书运营不是演示，已经有员工电脑在用，使用中暴露的问题（安装、升级、数据口径）正在被逐个修掉。
- **每新增一个岗位，成本在下降**：身份、权限、知识、模型、审计这些通用能力已经在中枢里；下一个岗位只需要做自己的应用，并提供一份接入说明，控制台不用改代码。
