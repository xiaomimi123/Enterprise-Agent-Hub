# 10 下一步与需要老板决策的事项

## 10.1 近期计划

| 事项 | 说明 |
|---|---|
| 补齐知识库 | 按冲剂、饮料产品重写「品牌与产品」知识库，需要产品资料表、包装图、配料表、检验报告、价格表 |

| 运维基础 | 备份恢复演练、监控告警、密钥轮换；在上云之前完成 |

## 10.2 需要老板拍板的事

1. **试点范围与周期**：从哪些员工开始，试点多久，用什么指标评估（例如每人每周做出的笔记数、选题采用率、模型花费）。
2. **是否上云及时间**：什么时候把中枢从本机迁到香港云服务器。
3. **第二个落地岗位**：下一个做哪个岗位的应用（设计、视频、销售等），由谁负责业务标准。
4. **知识库负责人**：品牌、产品、违禁词等知识库由谁负责维护和复核。
5. **预算口径**：模型和算力的月度预算，以及岗位包额度的设置原则。

## 10.3 附：术语

| 术语 | 说明 |
|---|---|
| AI 助手 / agent | 员工使用的 AI 工具，如 WorkBuddy、CodeBuddy |
| MCP | 让 AI 助手调用外部工具的开放协议，中枢以它对外提供能力 |
| 岗位包 | 一个岗位的权限、知识、模型、应用和额度的组合 |
| 技能 | 公司规定的工作做法（步骤和标准） |
| 接入器 | 装在员工电脑上的小程序，负责登录、续期、同步技能、连接中枢 |
| 应用 | 由中枢发布、在员工本机运行的业务工具，如小红书运营工作台 |
| 应用健康 | 员工电脑上的安装和运行错误自动汇总到控制台的功能 |
