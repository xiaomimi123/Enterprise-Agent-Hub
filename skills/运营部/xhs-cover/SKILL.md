# 封面图生成

## 什么时候用
运营写完笔记正文后，需要配一张封面图。

## 步骤
1. 读取笔记标题和正文，提炼一句 8–12 字的封面主文案
2. 检索知识库「品牌调性与人设」「视觉规范与素材」，确定配色和字体
3. 调用工具 `image.cover`，生成 3 版封面（大字报 / 产品特写 / 场景图）
4. 把 3 张图和主文案返回给员工挑选

## 规则
- 封面文案同样要过「违禁词与广告法自查」
- 不得使用未授权的明星或博主肖像
- 生成任务排队超过 5 分钟时，告知员工预计等待时间
