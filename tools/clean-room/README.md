# 干净机器验收（Windows 沙盒）

每次发版前，在**全新的 Windows** 里走一遍员工的安装流程：Win+R 一行命令 → 安装前自检 → 安装（演练，停在登录前）。开发机装了一切，永远复现不了员工电脑的问题；沙盒每次启动都是新系统。

## 一次性准备（在你的电脑上）

1. Windows 10 / 11 **专业版**（你的是 Windows 10 专业版）。
2. 控制面板 → 启用或关闭 Windows 功能 → 勾选 **Windows 沙盒** → 重启。（目前这台电脑上该功能是「已禁用」，需要你自己开；这是系统设置，我没有动。）
3. BIOS 里开启虚拟化。

## 运行

```powershell
powershell -ExecutionPolicy Bypass -File tools\clean-room\start.ps1 -Hub http://192.168.0.41:8088
```

会弹出一个沙盒窗口，自动跑完后在当前终端打印报告。退出码 0 = 自检没有 FAIL。

## 它验证什么，不验证什么

- 验证：全新系统上自检能跑、中枢能连、安装脚本演练能走到登录前、错误码和提示正确。
- **不验证**：浏览器采集（按约定不在开发机上测）、CodeBuddy 登录、「让 WorkBuddy 代跑」时的沙箱拦截（沙盒里没有 WorkBuddy，这一遍只能在真机上手测）。
- 沙盒的网络出口和员工电脑不同（没有公司的杀软和代理），所以「沙盒通过」不等于「所有员工机通过」，只是排除了「环境脏」这类因素。
