# 虚拟机测试步骤：ego lite + ego-reader + CodeBuddy

目的：在一台干净的 Windows 虚拟机上，从零走一遍「装 ego lite → 登录小红书 → ego-reader → CodeBuddy 读取」，对比 WorkBuddy 路线的便捷程度和错误率。每一步记下**通过 / 失败、耗时、错误原文**。

> 提醒：ego lite 的 Windows 安装包目前只有 **x64**。如果虚拟机是 Windows 11 **ARM64**（Apple 芯片的 Mac），它靠系统转译运行，可能更慢或不稳定；遇到奇怪问题请先注明架构。

## 0. 前提

- 虚拟机已用安装命令装完（有 `%USERPROFILE%\HubApps\runtime\node`、已能 `codebuddy -p "只回复：PONG"`）
- 任务空间规则：**只用一个任务空间**（`hub-xhs-reader`）。测试过程中不要手动再开别的任务空间

## 1. 安装 ego lite（手动，约 3 分钟）

1. 浏览器打开 `https://lite.ego.app/` 下载 Windows 版（或 GitHub 仓库 README 里的 Windows 按钮），运行安装程序。记录：**下载速度 / 是否能下载**。
2. 打开 ego lite，完成首次设置。**不要导入 Chrome 数据**（干净验证）。
3. **新开一个终端**（PATH 对已开的终端不生效），运行：
   ```
   ego-browser skill
   ```
   能打印出一份「usage guide」就算通过。

## 2. 登录小红书（本人操作）

在 ego lite 里打开 `https://www.xiaohongshu.com`，用手机扫码登录。验证码 / 风险提示由你本人处理。记录：**是否出现验证码或风险提示**。

## 3. 放好 ego-reader 并跑测试

1. 把 `ego-reader` 文件夹（含 `server.mjs`、`test.mjs`）复制到虚拟机，例如 `C:\Users\<你的用户名>\HubApps\tools\ego-reader\`。（开发机上已打好包：`D:\ego-reader-0.1.0.zip`）
2. 用安装时自带的 Node 跑校验测试（不需要浏览器）：
   ```
   %USERPROFILE%\HubApps\runtime\node\node.exe %USERPROFILE%\HubApps\tools\ego-reader\test.mjs
   ```
   期望：最后一行「全部通过」。
3. 再跑真实读取（会读信息流和 2 篇笔记，约 1 分钟）：
   ```
   %USERPROFILE%\HubApps\runtime\node\node.exe %USERPROFILE%\HubApps\tools\ego-reader\test.mjs --live
   ```
   期望：最后一行「全部通过」。

## 4. 接到 CodeBuddy

在虚拟机**自己的终端**里（不要在 WorkBuddy 里）运行（路径按实际修改）：

```
codebuddy mcp add ego-reader --scope user -- "%USERPROFILE%\HubApps\runtime\node\node.exe" "%USERPROFILE%\HubApps\tools\ego-reader\server.mjs"
```

然后运行 `codebuddy`，对它说：

> 用 ego-reader 的 xhs_read_feed 读一下小红书首页，列出你看到的 3 条笔记标题。

CodeBuddy 会询问是否允许调用这个工具，选允许。再说：

> 用 xhs_read_note 读其中第一条笔记，告诉我标题、作者、正文开头和点赞数。

## 6. 不要做

- 不要点赞、收藏、关注、评论；不要让 CodeBuddy 去做这些（工具里也没有）
- 不要连续大量读取：封装限制两次读笔记至少间隔 20 秒、每小时最多 12 篇，测试时不用试图绕过
- 测试完想停用：在虚拟机里创建文件 `%TEMP%\hub-ego-reader.STOP`，工具会全部拒绝
